# Data availability wording after upload

Replace the bracketed address with the actual public GitHub repository URL **after uploading**, then use this text in the manuscript:

> The code and experimental data supporting this study are available at [actual public repository URL]. The repository includes the MOHOA and comparison implementations, benchmark instances, author-specified power parameters, per-run results, final objective matrices, reference fronts, and data used to generate the tables and figures.

This wording describes the compact release accurately. It does not claim that every generation's history or every algorithm's final decision matrix is included. A tagged release or an archived release identifier can be added once one actually exists.
